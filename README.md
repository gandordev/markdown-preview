# Markdown Preview

Allow to create and preview markdown files directly in your editor.


## Requirements
uv>=0.9.21 or python>=3.14


## How to use

You can convert in two ways:

1. Using terminal

uv sync
uv run markdown-preview {file_path} or markdown-preview {file_path}
